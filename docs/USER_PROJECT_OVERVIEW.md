# 项目说明（给自己/老师看）

这个项目是在宇树 G1 机器人上做水瓶抓取实验，硬件上用 G1 左臂配合强脑 Revo2 左灵巧手，目标是从固定轨迹抓取逐步过渡到视觉辅助的自动化抓取。

目前已经完成了几部分基础工作。第一部分是机械臂和灵巧手的基础联动：左臂可以按固定轨迹移动到水瓶附近，Revo2 左手可以按“张手、拇指准备、五指闭合”的顺序抓瓶。现在整理了一个独立全流程脚本，手部控制和机械臂轨迹都写在同一个主脚本里，但不再依赖单独的左手测试脚本；流程是抓到瓶子后小臂抬起、悬停 3 秒、再放回原位并收手。第二部分是视觉检测：已经接入 YOLO 检测水瓶，并结合深度相机记录水瓶位置、目标点和随机点数据，能够输出当前水瓶相对目标抓取位置的偏差。第三部分是预抓姿态调参：现在可以通过小幅调整 G1 左臂关节偏移，让手逐步对准瓶子，再观察抓取效果。

最近重点在做“视觉到机械臂动作”的中间层，也就是先不直接闭环控制机械臂，而是用视觉检测结果判断瓶子是否在可抓范围内，并把偏差转成可以人工验证的小幅关节修正。这样做比较稳妥，能避免一开始就把不稳定的视觉结果直接用于手臂运动。

当前整理出来的项目资料已经按恢复出厂设置后的继续开发需要备份到了 GitHub。仓库里包含抓瓶主项目、独立抓放脚本、左右手诊断脚本、灵巧手控制脚本、视觉检测脚本、ROS2 视觉/标定源码、GUI 控制终端源码、可上传的小模型和调试记录。超过 GitHub 单文件限制的大模型没有上传，已经单独放在本机备份目录。

下一步建议继续做三件事：先恢复机器人环境和项目目录，验证 `arm_pick_place_standalone.py` 的固定轨迹抓放流程还能正常运行；再恢复 YOLO + 深度相机检测，确认能稳定输出水瓶中心、深度和偏差；最后开始做手眼标定，把相机坐标和机器人坐标对应起来，再进入真正的轨迹规划和自动抓取流程。
